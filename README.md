# Project2

## 推荐的地址空间安排

| 地址范围               | 建议用途                       |
|------------------------|-------------------------------|
| 0x50000000–0x50200000  | BBL代码及其运行所需的内存       |
| 0x50200000–0x50500000  | Kernel的数据段/代码段等         |
| 0x50500000–0x52000000  | 供内核动态分配使用的内存       |
| 0x52000000–0x52500000  | 用户程序的数据段/代码段等       |
| 0x52500000–0x60000000  | 使用用户动态分配的内存         |
